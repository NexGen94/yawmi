# يومي

تطبيق شخصي لمتابعة الأهداف والعادات اليومية، واجهته بالعربية من اليمين إلى اليسار. يعرض ما يخص اليوم، ويسجّل الإنجاز، ويحسب الدرجات والمؤشرات، ويقترح سطرين كحد أقصى من الذكاء الاصطناعي بمخرجات مقيّدة بمخطط. اليوم بتوقيت `Asia/Riyadh`، وبداية الأسبوع الأحد. المستودع خاص، ولا يحوي أسراراً.

## هيكل المستودع

| المسار | ما فيه |
|---|---|
| `api/` | خدمة FastAPI (حزمة `yawmi`)، وهي التنفيذ المرجعي لقواعد العادات والدرجات |
| `web/` | تطبيق الويب PWA |
| `YawmiKit/` | حزمة Swift: `Domain` و`SyncClient` |
| `openapi/` | مواصفة OpenAPI المثبّتة في المستودع، وتُولَّد من الخدمة |
| `contracts/domain-vectors/v1/` | متجهات اختبار مشتركة، تجتازها بايثون وTypeScript وSwift |
| `deploy/` | ملفات النشر وcompose ودليل التشغيل |

## تشغيل الاختبارات

يلزم Python 3.13 وأداة `uv`:

```bash
cd api
uv sync --all-groups
uv run pytest -q
uv run ruff check .
```

الأسرار لا تُحفظ هنا: تُقرأ من volume الأسرار أو من بيئة الحاوية وقت التشغيل.
